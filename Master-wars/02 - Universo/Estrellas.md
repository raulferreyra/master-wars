# Estrellas

Cada sistema tiene una sola estrella. Su tipo determina el perfil térmico general del sistema y modifica las probabilidades de las propiedades de sus planetas; no sustituye las reglas de habitabilidad de cada planeta.

| Tipo | Perfil | Tendencia de generación |
| --- | --- | --- |
| Enana blanca | Sistema antiguo y energético | Mayor radiación en órbitas internas; minerales densos y mundos hostiles. |
| Mediana amarilla | Sistema estable | Mayor probabilidad de órbitas templadas y diversidad de planetas. |
| Gigante roja | Sistema cálido y expansivo | Órbitas internas extremas; mayor presencia de mundos áridos y gaseosos. |

El tipo de estrella es visible para el jugador y no cambia durante la vida del universo.
