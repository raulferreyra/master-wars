# Títulos

Los títulos expresan trayectoria, no poder automático. Un jugador desbloquea varios mediante logros y puede elegir uno como título visible.

Cada raza usa una denominación propia para su identificador de incorporación, pero todos siguen la misma regla: el número refleja el orden de creación completada de esa raza dentro del universo, no se reutiliza y puede tener huecos.

| Raza | Denominación pública |
| --- | --- |
| Humanos | Misión |
| Marcianos | Cátedra |
| Venusianos | Velo |
| Guepardia | Zancada |
| Lupertos | Camada |
| Rinocerontia | Bastión |
| Automatia | Serie |
| Mechia | Forja |
| Robotta | Nodo |

Ejemplos de títulos desbloqueables: Capitán por capacidad militar, Administrador por gestión económica y Explorador por descubrimientos. Sus requisitos definitivos se documentarán con los sistemas de progreso.
