# Lunas

Un planeta puede tener de 0 a 3 lunas. La masa, el tamaño y la historia geológica del planeta afectan su probabilidad de aparecer, pero el límite de tres nunca se supera.

Las lunas se registran como cuerpos asociados al planeta, no como órbitas adicionales del sistema. Inicialmente pueden aportar espacio para instalaciones orbitales, sensores o puestos logísticos; sus efectos concretos se definirán junto con [[Construcción]] y [[Flotas]].
