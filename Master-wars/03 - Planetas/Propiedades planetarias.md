# Propiedades planetarias

Cada planeta conserva propiedades base y propiedades derivadas. Las primeras se generan al crear el universo; las segundas se calculan a partir de ellas y se actualizan únicamente cuando una regla explícita lo permita.

## Propiedades base

- Masa y tamaño.
- Composición de roca, metal, hielo o gas.
- Distancia orbital y tipo de estrella.
- Atmósfera, agua y vegetación.
- Temperatura, radiación y actividad geológica.

## Propiedades derivadas

- [[Habitabilidad]].
- Capacidad de construcción y población.
- Densidad y tipo de [[Recursos]].
- Riesgos ambientales y costes de mantenimiento.
- Probabilidad y límite de [[Lunas]].

Las propiedades base no se muestran como una puntuación escondida: la interfaz debe presentar sus efectos relevantes para que el jugador pueda decidir.
